# Segundo cerebro para creadoras

Guía corta, en español y gratuita, para armar un "segundo cerebro": una carpeta de notas en texto simple (Markdown) donde juntás tus ideas, proyectos y ventas, y que podés usar junto con un asistente de IA como Claude para ordenarla y trabajar más rápido.

Está pensada para creadoras y emprendedoras independientes (por ejemplo, quienes venden ebooks, cursos o productos digitales), pero sirve para cualquier persona que quiera tener sus notas en orden.

## Qué vas a encontrar acá

- [`01-estructura.md`](01-estructura.md): cómo organizar la carpeta de notas.
- [`02-trabajar-con-ia.md`](02-trabajar-con-ia.md): cómo usar un asistente de IA sobre tus notas, con ejemplos de pedidos.
- [`LICENSE`](LICENSE): podés copiar, adaptar y compartir esta guía.

## Idea central

1. **Una sola carpeta** con archivos de texto (`.md`) en vez de notas desparramadas en muchos lugares.
2. **Una nota por tema:** un proyecto, una idea, una persona o un producto.
3. **Un asistente de IA** que lee esa carpeta y te ayuda a resumir, ordenar, redactar y planificar.
4. **Revisión humana:** vos decidís siempre qué se guarda y qué se publica.

## Importante

No pongas en esta carpeta datos privados si la vas a publicar: contraseñas, números de tarjeta, datos de clientas o documentos personales. Si querés compartir tu carpeta real, usá un repositorio privado y publicá solo la plantilla vacía.

## Cómo contribuir

Si encontrás un error o querés sumar una idea, abrí un *issue* o un *pull request*. Todas las sugerencias son bienvenidas.
