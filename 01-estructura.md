# 01 · Estructura de la carpeta

Una estructura simple alcanza. Esta es una propuesta para empezar:

```
mi-segundo-cerebro/
├── 00-inbox/        ideas sueltas, para ordenar después
├── proyectos/       un archivo por proyecto o producto
├── clientas/        notas sobre personas y consultas (solo en repo privado)
├── ideas/           ideas de productos, contenidos y campañas
├── aprendizaje/     lo que estás estudiando o practicando
└── plantillas/      moldes para crear notas nuevas
```

## Reglas de oro

- **Un tema, un archivo.** Nombres claros, en minúscula y con guiones: `ebook-velas.md`.
- **Poné la fecha** cuando algo cambia: `2026-11-18: definí el precio`.
- **Escribí para tu yo del futuro.** Si en tres meses no lo entenderías, falta contexto.
- **Vaciá el inbox** una vez por semana: cada idea va a su carpeta o a la basura.

## Plantilla de nota de proyecto

```markdown
# Nombre del proyecto

- **Qué es:**
- **Para quién:**
- **Estado:** idea / en marcha / terminado
- **Próximo paso:**

## Decisiones
- fecha: decisión

## Pendientes
- [ ] tarea
```

Copiá esta plantilla cada vez que empieces un proyecto nuevo.
